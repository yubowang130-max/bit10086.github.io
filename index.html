Scientify: autonomous scientific discovery agents

Co-developed an LLM-agent framework that learns from evolving literature and generates research hypotheses. I built API orchestration, figure-digitisation skills, and local inference workflows for large-scale ablations.

02 / 3D + RL2026

Generative 3D scenes for UAV reinforcement learning

Built an end-to-end pipeline for simulator-ready environments: generated scenes and assets, estimated support surfaces, checked collisions, and composed 3D Gaussian Splatting worlds for a downstream UAV RL loop.

03 / GEO AI2024—25

Mars landing-site selection from terrain constraints

Built a geospatial pipeline that combines illumination and slope constraints to rank candidate landing zones, turning Martian DEM evidence into an inspectable selection workflow.

  • Terrain analysis
  • DEM

04 / SIGNALS2025

Radar emitter recognition with DBSCAN + Transformer

Designed a two-stage pipeline for clustering pulse streams and classifying emitter types. It reached 89% accuracy, a 12-point absolute improvement over the CNN baseline on the same dataset.

  • DBSCAN
  • Signal analysis
